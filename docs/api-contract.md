# API contract

Interactive OpenAPI documentation is generated at `/docs`.

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Prototype health and connection disclaimer |
| POST/GET | `/api/reports` | Idempotent report submission and filtered/paginated list |
| GET/PATCH | `/api/reports/{report_id}` | Retrieve/correct structured incident data |
| POST | `/api/reports/{report_id}/extract` | Deterministic extraction |
| POST | `/api/reports/{report_id}/find-duplicates` | Candidate duplicate list; human review only |
| POST | `/api/reports/{report_id}/calculate-priority` | Explainable priority result |
| POST | `/api/reports/{report_id}/verify` | Set coordinator verification status |
| POST | `/api/reports/{report_id}/mark-duplicate` | Record coordinator duplicate decision |
| GET/POST/PATCH | `/api/resources[/{resource_id}]` | Resource inventory and availability |
| POST | `/api/allocations/recommend` | Feasible greedy recommendations |
| POST | `/api/allocations/approve` | Confirm assignment after availability recheck |
| POST | `/api/allocations/reject` | Record a rejected recommendation |
| POST | `/api/evidence/upload` | Restricted upload and SHA-256 record |
| POST | `/api/evidence/{evidence_id}/verify` | Compare stored file bytes with hash |
| GET | `/api/audit` | Chronological prototype event log |
| POST | `/api/demo/load` | Seed synthetic flood data |
| POST | `/api/demo/reset` | Restore the original synthetic dataset |
| POST | `/api/demo/simulate-route-change` | Simulate blocked route or unavailable resource |

Report IDs are generated by the client and used as idempotency keys. `created_at` is citizen-side report time; `received_at` is API receipt time. List responses include `items`, `total`, `offset`, and `limit`.
